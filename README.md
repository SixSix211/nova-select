# NOVA SELECT

一个参考移动端精品商城结构、重新设计视觉语言的选品商城。

## 本地预览

可直接双击 `index.html` 查看演示商品，或使用任意静态服务器。例如已安装 Python 时执行：

```powershell
python -m http.server 4173
```

然后打开 <http://localhost:4173>。

## 已包含

- 响应式移动端优先布局，也适配桌面宽屏
- 首页、分类、购物车、个人中心四个视图
- 搜索过滤商品
- 分类筛选
- 加入购物车、数量增减、移除商品
- 无支付订单提交表单
- Supabase 商品数据库接入
- 管理员邮箱登录
- 商品新增、编辑、删除、上下架及图片上传
- 客户订单查看和状态管理
- 自包含 SVG 商品视觉，不依赖图片资源
